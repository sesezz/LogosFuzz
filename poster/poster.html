핵심 기술

//

Bazel 빌드 그래프 인지

strict deps·visibility 를 강제하는 환경에서 정답을 아는 건 bazel query 뿐. 타깃 경계를 넘는 API 는 한 그룹으로 묶지 않습니다.

↻

실측 코퍼스 기반 자가치유

실제로 빌드를 깨뜨려 모은 에러 원문으로 10종 분류기를 구성. 고칠 수 없는 결함은 LLM 호출 없이 즉시 에스컬레이션합니다.

✓

검증된 하네스만 실행

퍼즈 입력을 쓰지 않는 하네스는 커버리지만 나오고 새 경로가 없습니다. 입력 소비 검증으로 헛도는 캠페인을 사전에 차단합니다.
