## 요약
LogosFuzz 퍼징 과정에서 함수 `void score_channel_close(ScoreChannel *ch)` 호출 경로에서 AddressSanitizer가 heap use after free를 탐지했다. 대상 라이브러리: eclipse-score. LLM 기반 정탐/오탐 판별 결과: true_positive (신뢰도 0.88). harness가 score_channel_destroy 호출 후 동일 채널 핸들로 score_channel_close 를 다시 호출하는 API 순서 위반 시나리오지만, 실제 소비자 코드(예: 콜백 해제 경로)에서도 동일한 이중 정리(double-teardown) 패턴이 발견되어 실제 도달 가능한 결함으로 판단.
