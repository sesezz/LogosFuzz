# [LOGOSFUZZ-2026-000001] dlt-daemon: heap buffer overflow (/src/dlt-daemon/src/shared/dlt_common.c:842:12)

> 상태: `draft` · 발견일시: 2026-07-25T18:37:57.231809+00:00 · 도구: LogosFuzz + AFL++/libFuzzer + AddressSanitizer

## 요약
LogosFuzz 퍼징 과정에서 함수 `int dlt_message_read(DltMessage *msg, uint8_t *buffer, unsigned int length, int resync, int verbose)` 호출 경로에서 AddressSanitizer가 heap buffer overflow를 탐지했다. 대상 라이브러리: dlt-daemon. LLM 기반 정탐/오탐 판별 결과: true_positive (신뢰도 0.93). 스택트레이스가 dlt_message_read 내부의 헤더 길이 필드(length)를 검증 없이 그대로 사용해 4바이트 초과 읽기가 발생함을 보여준다. 할당 크기(4바이트)와 읽기 시도 위치가 정확히 경계 바로 다음이며, 재실행 시 100% 재현되어 정탐으로 판단.
